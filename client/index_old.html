CampusGuide: System Architecture & Execution

Explore Source Code arrow_forward

THE PROBLEM

Students face scattered university communication across uncoordinated WhatsApp groups, notice boards, and informal threads, leading to missed mentorship programs, disorganized club activities, and fragmented schedules.

THE ARCHITECTURAL SOLUTION

Built an integrated single-page React frontend supported by an Express/Node backend. Implemented normalized relational schemas in MySQL, stateless JWT session authentication, and WebSocket streams for immediate event broadcasts.

KEY OUTCOMES

Delivered structured mentorship matchmaking, an organized student club directory, automated push notifications, and verified campus profile management with responsive mobile UX.

CampusGuide • In-Depth Architecture

Built for Université Nouveaux Horizons Student Ecosystem

Architecture Highlights

  • Front-end: Modular React components styled with Tailwind CSS utility classes.
  • Backend: Express.js routing layer with controllers and service-pattern isolation.
  • Database: MySQL schema with relational foreign keys for users, clubs, events, and mentorship pairings.
  • Real-Time: WebSockets (Socket.IO) handling live club broadcasts and instant mentor alerts.

Key Challenges Solved

Handling state synchronization across mentor session scheduling while preventing double bookings. Resolved via transactional row locks in MySQL and optimistic client UI updates.
